## Key takeaways for implementation

1. **Ship first:** Pexels (REAL_API, fully verified, free 200 req/hr + 20k req/mo, direct no-watermark video URLs) — this is the one provider safe to build provider priority #1 on with confidence.
2. **Ship with caveats:** Pixabay and Unsplash (official APIs exist; rate limits/license details still need one successful official-doc fetch); Wikimedia Commons and Openverse (real APIs, per-asset attribution required — Openverse is image/audio only, video unconfirmed; Commons needs API-etiquette compliance).
3. **Coverr** is a real API but **non-commercial** — only usable if the app's output context qualifies; otherwise exclude.
4. **Freepik** is a real API but usage-based paid and its license explicitly bans stock-library inclusion/redistribution — do not treat as a free B-roll source.
5. **Manual/future only:** Mixkit (hard no — terms forbid bots/scraping), Videvo (no API), Dareful (no API + sparse license terms).
6. **Recommended follow-ups:** re-fetch `https://pixabay.com/api/docs/` (rate limits, 24h-cache rule, license/redistribution rules), `https://unsplash.com/documentation` + `https://unsplash.com/api-terms` (rate limits, attribution/hotlinking rules), `https://www.pexels.com/license/` (commercial caveats), `https://www.mediawiki.org/wiki/API:Etiquette` (bot rules), and Openverse's full ToS at `https://wordpress.github.io/openverse-api/terms_of_service.html`.
