## Notes — PROFILE CONTRACT (how profile params are really consumed)

backend/editing.py documents the contract; the real effects are:
  pacing_target   -> target seconds/scene when grouping sentences (plan builder)
  music_energy    -> bed-music ducking/selection energy at export (0..1)
  text_style      -> drawtext preset family: lower-third/caption/bold-title/minimal/kinetic
  transition_bias -> default transition stamped on segments lacking one
apply_editing_settings() already stamps transitions and trims overlays per
text_density (low: ≤1 overlay per 2 scenes, preferring date/stat; medium: ≤1
per scene; high: keep all). window.EditingUI.getSettings() exposes the user's
{sourceMode, creativeMode, profile} to the pipeline, and per-scene footage
ordering can use filter_sources(candidates, user_media, mode) with the
selected source mode. Scene locks set clip.locked, which the existing
regenerateClip() already refuses to touch.
